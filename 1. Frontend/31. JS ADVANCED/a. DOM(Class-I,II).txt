* Automatically created when a browser tab opens.

# DOM(Document Object Model):- The DOM represents the structured content (HTML/XML) of a web page as a tree of objects. 
It allows JavaScript to access, modify, and update the content, structure, and style of the page.
The HTML/whole code which we convert into Javascript Object is called DOM.

All the tasks that are related to HTML, it's structure and it's manipulation are all handled by DOM whereas the tasks which are
performed by URL or browser returns it in response are handled by BOM.

# CONCEPT OF UPDATING EXISTING CONTENT OF WEBPAGE:-

1. INNER HTML:- The innerHTML property is used to access or modify(get/set) the HTML content of an element.
When you use the innerHTML property, it reads both the HTML markup and the text content of the element. 
This means when you use it to set the content of elements, you can include HTML tags, and the browser will render them correctly. 
Eg:- 

<div id="demo1">
  <b>Hello</b> World!
</div>

<script>
    console.log(document.getElementById("demo1").innerHTML);
    // Output: <b>Hello</b> World!
</script>


EG:- <div id="content">Original Content</div>

     // Select the element
     let contentDiv = document.getElementById('content');

     // Update the content with new HTML
     contentDiv.innerHTML = '<p>New <strong>HTML</strong> content with <a href="#">a link</a>.</p>';

     RESULT:
     <div id="content">
      <p>New <strong>HTML</strong> content with <a href="#">a link</a>.</p>
     </div>



2. OUTER HTML:- Returns or sets the entire HTML element including its own tag and its content.
                Used when we want to replace or retrieve the element along with its HTML structure.

* Use innerHTML when you only need to modify or retrieve the content inside an element, such as updating text or adding new HTML elements within a container.
* Use outerHTML when you need to replace or retrieve the entire element, including its attributes and tags.

EG:- let element = document.querySelector('.company');
     element.outerHTML;
     // Output: '<p class="company text-xl text-textpara">Ex-Amazon, <b>SWE</b></p>'

     element.outerHTML = '<div class="new-company">Ex-Google, <i>SWE</i></div>';
     // This replaces the entire <p> element with a <div> element




    <div id="demo2">
      <i> Hi </i> there!
    </div>

    <script>
      console.log(document.getElementById("demo2").outerHTML);
    / / Output: <div id="demo2"><i>Hi</i> there!</div>
    </script>


InnerHTML is used for getting or setting a content of the selected tag while outerHTML is used for getting or setting content along with the selected tag.


3. TEXT CONTENT:- Returns or sets the text content of an element and all its descendants. Ignores hidden elements and does not interpret HTML tags.
Used when you want the raw textual content (faster than innerText).
It also returns all text, whether it's rendered on screen or not.

EXAMPLE:-   <div id="example">
                <p>This is <span>some</span> text.</p>
                <p style="display:none;">This text is hidden.</p>
            </div>

            <script>
                let element = document.getElementById('example');
                console.log(element.textContent);  // Outputs: "This is some text.This text is hidden."
            </script>


4. INNER TEXT:- This property focuses on the rendered text content. 
When you use innerText to read the content of an element, it returns the text as it appears on screen. 
It ignores HTML tags. And it also does not include text that is hidden with CSS styles.

EXAMPLE:-    <div id="example">
                <p>This is <span>some</span> text.</p>
                <p style="display:none;">This text is hidden.</p>
            </div>

            <script>
                let element = document.getElementById('example');
                console.log(element.innerText);  // Outputs: "This is some text."
            </script>

# Since we know that by inserting a para and its content in the above manner will have an impact on position such that 
it will be placed at last of the class or tag under which it is appended forEg; we can't insert outside the element, like before or after it.
so, we use insertAdjacentElement() method that inserts a an existing element into a specified position providing more flexibilty.
SYNTAX: insertAdjacentElement(position, element)

VALUES:- 

EG:- <div id="target">Target Element</div>


(a.) beforebegin - Inserts the new element immediately before the target element, as a sibling.


// Create a new element
let newElement = document.createElement('p');
newElement.textContent = 'I am inserted before the target element.';

// Insert the new element before the existing target element
let target = document.getElementById('target');
target.insertAdjacentElement('beforebegin', newElement);

RESULT:-
<p>I am inserted before the target element.</p>
<div id="target">Target Element</div>



(b.) afterbegin - Inserts the new element as the first child of the target element.


// Create a new element
let newElement = document.createElement('p');
newElement.textContent = 'I am the first child inside the target element.';

// Insert the new element as the first child of the target element
let target = document.getElementById('target');
target.insertAdjacentElement('afterbegin', newElement);

RESULT:-
<div id="target">
  <p>I am the first child inside the target element.</p>
  Target Element
</div>



(c.) beforeend - Inserts the new element as the last child of the target element.

// Create a new element
let newElement = document.createElement('p');
newElement.textContent = 'I am inserted after the target element.';

// Insert the new element after the target element
let target = document.getElementById('target');
target.insertAdjacentElement('afterend', newElement);

RESULT:-
<div id="target">Target Element</div>
<p>I am inserted after the target element.</p>



(d.) afterend - Inserts the new element immediately after the target element, as a sibling.


// Create a new element
let newElement = document.createElement('p');
newElement.textContent = 'I am the last child inside the target element.';

// Insert the new element as the last child of the target element
let target = document.getElementById('target');
target.insertAdjacentElement('beforeend', newElement);

RESULT:-
<div id="target">Target Element</div>
<p>I am inserted after the target element.</p>

# DIFFERENCES BETWEEN  insertAdjacentHTML and insertAdjacentElement:-
Content Type:
* insertAdjacentHTML: Takes a string of HTML.
* insertAdjacentElement: Takes an existing DOM element.

Usage Context:
* insertAdjacentHTML: Useful when you have HTML as a string that you want to parse and insert.
* insertAdjacentElement: Useful when you already have a DOM element (created with JavaScript) that you want to insert.

Parsing: Parsing is the process of analyzing and converting a string of text into a structured format that a program or browser can understand and manipulate.
In web development, parsing involves interpreting HTML, CSS, and JavaScript strings to create or manipulate the DOM and apply styles or execute code.
Methods like insertAdjacentHTML rely on parsing to convert HTML strings into DOM elements that can be inserted into the document.
* insertAdjacentHTML: The string of HTML is parsed and then the resulting elements are inserted.
* insertAdjacentElement: The element is directly inserted without any parsing.

Performance:
* insertAdjacentHTML: Can be more performance-intensive because it involves parsing HTML strings.
* insertAdjacentElement: Typically more efficient since it directly manipulates existing DOM elements without parsing.

# LEARNING TO STYLE PAGE CONTENT USING JAVASCRIPT:-

We can do styling in csss with the help of JavaScript in the following ways:-

1. style - The style property allows you to directly change a single CSS style property of an element via JavaScript. 
It accesses the inline style of the element.

EXAMPLE:

  const element = document.getElementById('myDiv');
  element.style.backgroundColor = 'lightblue';    // Sets background-color
  element.style.fontSize = '20px';                // Sets font-size

NOTE:- Notice that we’re using camelCase rather than adding a dash ("-") between the styling properties (e.g. fontWeight rather than font-weight).
This is required if we’re going to set CSS with JavaScript.




2. style.cssText - The cssText property of the style object lets us set multiple CSS style rules as a single string at once, 
overwriting any existing inline styles.

EXAMPLES:

  const element = document.getElementById('myDiv');
  element.style.cssText = 'background-color: lightblue; font-size: 20px; color: red;';





3. setAttribute - The setAttribute() method sets the value of an attribute on the specified element. It can be used to set the entire style attribute as a string,
allowing multiple CSS styles to be set at once, just like writing inline styles in HTML. 

 setAttribute() takes two arguments:
 * name - A string specifying the name of the attribute whose value is to be set.
 * value - A string containing the value to assign to the attribute. Any non-string value specified is converted automatically into a string.


EXAMPLE:
  const element = document.getElementById('myDiv');
  element.setAttribute('style', 'background-color: lightblue; font-size: 20px; color: red;');

// TOGGLE AND REPLACE PROPERTIES OF classList:

Purpose: Toggles a class on an element. If the class is present, it removes it; if the class is absent, it adds it.
Usage: Useful for switching states, like showing/hiding an element or turning a feature on/off.
Example:

element.classList.toggle('active');
If the element has the class active, this will remove it.
If the element does not have the class active, this will add it.
With Optional Force Parameter:

element.classList.toggle('active', true);  // Adds the class
element.classList.toggle('active', false); // Removes the class
The second argument forces the class to be added (true) or removed (false).

classList.replace
Purpose: Replaces an existing class with a new class.
Usage: Useful when you need to switch from one class to another, like changing themes or updating styles.
Example:


element.classList.replace('old-class', 'new-class');
If the element has the class old-class, this will replace it with new-class.
If the element does not have the class old-class, nothing happens.

# PHASES OF AN EVENT:-

There are three different phases during the lifecycle of a JavaScript event.

1. Capturing Phase - The event starts at the root of the DOM and travels down to the target element.
2. Target Phase - The event reaches the target element where it was originally triggered.
3. Bubbling Phase - After reaching the target element, the event travels back up the DOM tree to the root.
They follow the same order as listed above.


Capturing Phase is when the event goes down to the element. 
The target phase is when the event reaches the element and the Bubbling phase is when the event bubbles/goes up from the element to the top[parent].




EXAMPLE WITH PROPAGATION CONTROL:- 

document.getElementById('parent').addEventListener('click', function() {
    console.log('Parent clicked!');
}, true); // true makes it run in capture phase

document.getElementById('child').addEventListener('click', function(event) {
    console.log('Child clicked!');
    event.stopPropagation(); // Stops the event from bubbling up
});




# SYNTAX TO ENABLE IT: addEventListener(type, listener, useCapture)

By default, the event is in bubbling phase but if you want to change it to capture phase then:

addEventListener(type, listener, true); 
// Set useCapture to true in order to enable capture phase and false to change it to bubble phase.

There is no direct way to enable the target phase specifically when using addEventListener.
