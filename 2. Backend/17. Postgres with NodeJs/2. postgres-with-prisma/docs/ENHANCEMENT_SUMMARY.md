## 🔑 Advanced Prisma Features Demonstrated

### 1. **Relationships**
```prisma
// One-to-Many
model Author {
  books Book[]
}

// Many-to-Many
model Book {
  genres Genre[]  // Implicit junction table
}

// Self-cascading
model Author {
  books Book[] @relation(onDelete: Cascade)
}
```

### 2. **Transactions**
```javascript
// Complex multi-step operation
await prisma.$transaction(async (tx) => {
  // Check stock
  // Validate member
  // Create record
  // Update stock
});
```

### 3. **Unique Constraints**
```prisma
@@unique([bookId, memberId])  // One review per member per book
```

### 4. **Advanced Queries**
- Filtering with `where` conditions
- Pagination with `skip` and `take`
- Aggregations with `_count`, `_sum`
- Include nested relations

### 5. **Error Handling**
- Custom error messages
- Validation before operations
- Graceful error responses

## 🎓 Intermediate Concepts Covered

### ✅ Pagination
```javascript
const skip = (page - 1) * limit;
const [data, total] = await Promise.all([
  prisma.entity.findMany({ skip, take: limit }),
  prisma.entity.count()
]);
```

### ✅ Transactions
```javascript
await prisma.$transaction(async (tx) => {
  // Multiple operations as atomic unit
  // Rollback if any fails
});
```

### ✅ Aggregation
```javascript
const stats = await prisma.review.groupBy({
  by: ["rating"],
  _count: { id: true }
});
```

### ✅ Complex Filtering
```javascript
where: {
  OR: [
    { title: { contains: query } },
    { description: { contains: query } }
  ],
  AND: [
    { price: { gte: minPrice } },
    { price: { lte: maxPrice } }
  ]
}
```

### ✅ Relationship Management
```javascript
// Connect existing relations
data: {
  genres: { connect: genreIds.map(id => ({ id })) }
}

// Set relations (replace existing)
data: {
  genres: { set: genreIds.map(id => ({ id })) }
}
```
