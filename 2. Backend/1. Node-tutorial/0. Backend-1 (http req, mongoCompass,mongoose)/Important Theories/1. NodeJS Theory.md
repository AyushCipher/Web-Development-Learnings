1️⃣ What is Node.js? 
Ans - Node.js is an open-source, cross-platform JavaScript runtime environment that allows JavaScript to run outside the browser, mainly on servers.

Q.Why Node.js Was Created?

Ans - Before Node.js:

* JavaScript → only browser
* Backend → PHP, Java, Python
* Frontend + Backend → different languages

Node.js solved:

* One language (JavaScript) everywhere
* Faster development
* Better performance for I/O-heavy apps

Key Characteristics:-

Built on Chrome V8 Engine:

* Event-driven
* Non-blocking I/O
* Single-threaded
* Highly scalable*

Real-Life Example

* Like a restaurant waiter:
* Takes order
* Gives it to kitchen
* Serves other customers instead of waiting



2️⃣ JavaScript Engine & V8
What is a JavaScript Engine?

A program that executes JavaScript code.

What is V8?

* Developed by Google
* Written in C++
* Converts JavaScript → machine code
* Extremely fast

Q. Why Node Uses V8?

* High performance
* Just-in-time (JIT) compilation
* Optimized memory management

FLOW : JavaScript Code → V8 → Machine Code → Execution
