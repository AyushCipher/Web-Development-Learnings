# Web Development Learnings

A full-stack web development journey, learned one concept at a time and
turned into one project per concept - from raw HTML through modern React
on the frontend, and from a bare Node.js HTTP server through databases,
auth, real-time systems, microservices, and agentic AI on the backend.

This is a personal learning/practice repository, not a portfolio of
production services. The goal throughout is depth of understanding over
polish, with extensive Q&A-style comments in the source explaining not
just *what* the code does but *why* it's built that way.

## Structure

| Folder | Covers |
|---|---|
| [1. Frontend](<1. Frontend/README.md>) | HTML & CSS fundamentals through React, Hooks, Context, Redux, and TypeScript |
| [2. Backend](<2. Backend/README.md>) | Node.js fundamentals through databases, auth, real-time systems, microservices, Docker, and agentic AI |

Open either folder's README for a topic-by-topic breakdown of what's
inside and how to run it.

## How this repo is organized

Every numbered folder is a self-contained topic or project - most are
independently runnable (`npm install && npm run dev`, or just open the
`.html` file directly for the plain HTML/CSS folders). The numbering
reflects the order topics were learned in, not a strict dependency chain,
so folders can generally be explored in any order.
